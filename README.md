# Cours Python

Exercices réalisés en préparation de ma formation AI engineer à l'IPSSI Nice (rentrée décembre 2026).

## Contenu

| Leçon | Thème | Fichiers |
| --- | --- | --- |
| 1-2 | Algorithmique, listes et dictionnaires | `fichier_de_cours.py` |
| 3 | Lecture et écriture de fichiers JSON et CSV | `exo_7.py`, `exo9.py` |
| 4 | Gestion des erreurs avec try / except | `exo_10.py` |

## Lancer un exercice

python exo_10.py

Les scripts lisent `commandes.csv` ou `commandes_sales.csv` et produisent un `rapport.csv` (non versionné).
